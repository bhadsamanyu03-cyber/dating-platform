# User Journeys

## Confirmed identity journeys

1. A person registers with email and password, then receives an email-verification credential.
2. A person signs in with an existing email/password pair and receives an authenticated session.
3. A person refreshes an expiring session without re-entering credentials.
4. A person requests a password reset, receives a one-time credential, and sets a new password.
5. A person reviews active sessions and revokes a session.
6. A person changes a password or requests account deletion with password confirmation.

No future product journey is specified. Journey maps for onboarding, profile creation, discovery, matching, conversations, reporting, safety, and billing remain intentionally absent.
