# Glossary

- **Access token**: short-lived bearer credential used to call protected API routes.
- **Refresh session**: server-side record for a refresh credential and its lifecycle.
- **Refresh-token family**: related rotated refresh sessions; replay of a revoked member invalidates active members.
- **Credential version**: user value that invalidates previously issued access credentials when incremented.
- **Soft deletion**: account marked inactive/deleted without immediate physical removal.
- **One-time token**: expiring credential consumed once for email verification or password reset.
- **Product owner**: authority responsible for defining product decisions and approving scope.
- **Open question**: an undecided product or operational matter that must not be converted into behavior without approval.
