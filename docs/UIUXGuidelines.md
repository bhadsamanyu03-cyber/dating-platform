# UI/UX Guidelines

No product visual identity, navigation model, interaction model, content strategy, or design system has been approved. Future UX work must be based on product-owner decisions and user research, not assumed dating-app conventions.

## Confirmed baseline

Identity screens must clearly communicate validation outcomes, verification/reset actions, session-related security events, and destructive account actions. They must not expose security credentials in the UI or logs visible to users.

## Open Questions

- What brand, tone, visual system, and writing style are required?
- What information architecture and navigation model are desired?
- What onboarding, consent, safety, and deletion experiences should users have?
- Which empty, loading, offline, error, and recovery states are required?
