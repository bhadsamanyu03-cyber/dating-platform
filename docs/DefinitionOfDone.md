# Definition of Done

A product feature is done only when its product-owner-approved requirements, scope, exclusions, acceptance criteria, data model, API contract, authorization, privacy/safety implications, error behavior, observability, documentation, tests, accessibility, and deployment/rollback needs are complete and reviewed.

Implementation is not done when it merely compiles or presents a screen. Unresolved product decisions must remain open questions rather than being silently implemented.

## Open Questions

- Which roles must sign off on product, design, engineering, security, legal, and operations work?
- What evidence is required for each sign-off?
- Which items may be deferred and who accepts the resulting risk?
